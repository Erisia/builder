# arcrecycle (source)

The jar is shipped to clients and servers from `base/e36-third-party/mods/arcrecycle-1.1.0.jar`.
`./source` is the source it was built from (tsugumi-lab; Gradle/RetroFuturaGradle needs network access, so the jar is
prebuilt), and `./history.bundle` the git history (`git clone history.bundle`).
